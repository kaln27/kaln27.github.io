# Self-hosted editorial fonts

Manrope for headings and interface text; Source Serif 4 for prose.
Both are distributed under the SIL Open Font License, included alongside the fonts.
These are open-source alternatives used for the site design, not Anthropic font files.

Latin WOFF2 subsets obtained from the Google Fonts CSS API on 2026-11-02.
Chinese prose uses installed Songti / Noto Serif / Source Han Serif fallbacks;
Chinese headings and interface labels use the system sans-serif fallback.
