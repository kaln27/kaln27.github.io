OmniKey: Lifecycle-Aware Audiovisual Token Compression for Omni-Modal Large Language Models

Juncheng Liao · Second author

Overview

OmniKey studies efficient inference for omni-modal large language models with long audiovisual inputs. It reduces computation and KV-cache overhead while retaining temporal and cross-modal information.

The training-free framework analyzes representation lifecycles using truncated matrix entropy and combines block-wise audiovisual deduplication, Key-alignment-guided progressive pruning, and late-layer token exit. Token ranking uses inverse Key norms, and the method is compatible with FlashAttention.

Results

  • 25% audiovisual tokens retained on Qwen2.5-Omni-7B, retaining 98.6% of average performance across four benchmarks.
  • 3.44× decoder prefill speedup on WorldSense.
  • 4.55 GiB lower peak memory usage relative to the full-token input.

These figures refer to the reported experimental settings on Qwen2.5-Omni-7B.
